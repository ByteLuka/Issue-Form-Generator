## 1.0.0 (2026-11-04)

### Features

- Split view with guided editor (left) and live YAML / GitHub-style preview (right), resizable on desktop.
- Guided element creation: type picker followed by a step-by-step dialog.
- Support for all issue form element types: `markdown`, `input`, `textarea`, `dropdown`, `checkboxes`, `upload`.
- Support for all top-level keys: `name`, `description`, `title`, `labels`, `assignees`, `projects`, `type`.
- Drag & drop reordering, duplicate, delete with undo.
- Validation against GitHub's form schema with errors and warnings.
- Import of existing issue form YAML (paste or upload).
- Starter templates: bug report, feature request, documentation.
- Auto-save in the browser (localStorage).
- Light, dark and system color scheme.
- Copy and download of the generated YAML.
